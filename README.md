# Investment-Portfolio-Tracker
Project Summary:
An investment portfolio tracker was developed to analyse asset performance and monitor portfolio growth over time. Using an open-source dataset, investment activity was analysed to evaluate asset value progression, identify top-performing assets, and track overall portfolio growth. The results were presented through a visual dashboard designed to support investment monitoring and performance evaluation.
Project Overview:
In this project, an investment portfolio dataset was analysed to provide insights into asset performance and value growth. The analysis focused on understanding how individual assets contributed to the overall portfolio and how investment value evolved over time.
Key portfolio metrics were examined, including asset value progression, investment allocation, and asset performance comparisons.
The analysis was designed to simulate a personal investment tracking system, demonstrating how data analytics can be used to monitor and evaluate financial portfolios.
Objectives:
The project aimed to:
•	Track the progression of asset value over time
•	Identify top-performing assets within the portfolio
•	Analyse total investment allocated to each asset
•	Compare current asset value against invested value
•	Monitor overall portfolio growth trends
Analysis Performed:
Asset Value Progression
The progression of asset values over time was analysed to understand how the portfolio evolved and how individual investments contributed to portfolio growth.
Top Performing Assets
Assets were ranked based on performance to identify those generating the highest value growth within the portfolio.
Investment Allocation
Total investment amounts were calculated for each asset to understand how capital was distributed across the portfolio.
Current Asset Value Analysis
The current value of each asset was compared against the total invested value to evaluate investment performance.
Asset Growth Tracker
An asset growth tracker was developed to monitor performance trends and highlight assets demonstrating consistent growth over time.
Key Insights:
The analysis revealed several insights into portfolio performance:
•	Some assets demonstrated strong growth trends, contributing significantly to overall portfolio value.
•	Investment allocation patterns influenced portfolio performance and diversification.
•	Tracking asset progression helped identify high-performing investments and underperforming assets.
These insights illustrate how portfolio analytics can support investment monitoring and decision-making.
Tools & Technologies:
The project was developed using the following tools:
•	Power BI – dashboard development and data visualisation
•	Power Query – data cleaning and transformation
•	Data analysis techniques including trend analysis and performance comparison
Skills Demonstrated:
This project demonstrates key data analytics capabilities including:
•	Data cleaning and preparation
•	Financial data analysis
•	Performance tracking and trend analysis

Project Outcome:
An investment portfolio tracking dashboard was produced to provide a clear view of asset performance and portfolio growth. The dashboard enables investment trends to be explored and asset performance to be monitored in an accessible visual format.
