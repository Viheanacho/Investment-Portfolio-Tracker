# Investment-Portfolio-Tracker

## 1. Project Headline
**Investment Portfolio Tracker: An Interactive Power BI Dashboard for Asset Performance, Portfolio Growth, and Investment Monitoring**

## 2. Description / Purpose:
An investment portfolio tracker was developed to analyze **asset performance and monitor portfolio growth over time**. Using an open-source dataset, investment activity was analyzed to evaluate asset value progression, identify top-performing assets, and track overall portfolio growth.
The results were presented through a visual dashboard designed to support **investment monitoring, asset performance evaluation, and portfolio analysis**.
In this project, an investment portfolio dataset was analyzed to provide insights into asset performance and value growth. The analysis focused on understanding how individual assets contributed to the overall portfolio and how investment value evolved over time.
Key portfolio metrics were examined, including **asset value progression, investment allocation, current asset value, total returns, and asset performance comparisons**.
The analysis was designed to simulate a personal investment tracking system, demonstrating how data analytics can be used to monitor and evaluate financial portfolios through an interactive dashboard.

## 3. Tech Stack:
The project was developed using the following tools and technologies:
* **Power BI Desktop**: Used for dashboard development, data visualization, portfolio monitoring, and presentation of investment performance insights.
* **Power Query**: Used for data cleaning, transformation, and preparation of the investment dataset.
* **Data Modeling**: Used to structure the investment data and support analysis across investors, months, asset types, and risk profiles.
* **Data Analysis Techniques**: Trend analysis and performance comparison were used to evaluate asset growth and portfolio performance.
These tools enabled the transformation of raw investment records into an interactive portfolio tracking and performance monitoring dashboard.

## 4. Data Source:
The analysis was based on an **open-source investment portfolio dataset** containing information relating to investment activity, asset types, asset values, returns, quantities, investors, months, and risk profiles.
The dataset supported analysis across areas such as:
* Investor information
* Investment amount
* Current asset value
* Asset type
* Asset name
* Quantity held
* Total returns
* Return percentage
* Monthly investment activity
* Risk profile

### Data Acquisition:
An open-source investment dataset was sourced to simulate investment portfolio activity and provide a foundation for analyzing asset performance and portfolio growth.

### Data Cleaning and Transformation:
The data was prepared and transformed to ensure that investment values, returns, asset classifications, and other portfolio metrics could be analyzed consistently within Power BI.
The prepared dataset was structured to allow portfolio performance to be explored by **investor, month, asset type, and risk profile**.

## 5. Features and Highlights:
The following key analytical areas were prioritized and visualized within the dashboard:

### Portfolio Performance Overview:
The dashboard provides a high-level overview of portfolio performance through key metrics including:
* *Total Investment*
* *Total Current Value*
* *Total Returns*
* *Total Returns %*
* *Top Performing Asset*
These KPIs provide a quick view of the overall financial position and performance of the investment portfolio.

### Asset Value Progression:
The progression of asset value over time was analyzed to understand how the portfolio evolved and how investment values changed across different months.
The dashboard provides a visual trend of asset value progression, allowing users to identify changes in portfolio value over the selected period.

### Investment Allocation:
Total investment amounts were calculated for each asset to understand how capital was distributed across the portfolio.
The dashboard provides an asset-type breakdown covering categories such as:
* Commodity
* Debt
* Digital
* Equity
* Insurance
* Mutual Fund
* Property
This provides visibility into portfolio allocation and diversification across different asset categories.

### Current Asset Value Analysis:
The current value of each asset was compared against the total invested value to evaluate investment performance.
This allows users to examine how individual assets are contributing to the overall portfolio value and identify differences in performance across investments.

### Top Performing Assets:
Assets were ranked based on performance to identify those generating the highest value growth within the portfolio.
The **Top Performing Assets** visualization provides a focused view of the investments contributing strongly to portfolio performance, helping users identify assets that may warrant closer monitoring.

### Asset Growth Tracker:
An **Asset Growth Tracker** was developed to monitor asset performance and provide a comparative view of:
* Asset name
* Current value
* Total return
* Quantity
* Return percentage
* Return percentage by asset name
This provides a more granular view of individual asset performance and makes it easier to compare investments within the portfolio.

### Portfolio Growth Trends:
The dashboard tracks overall portfolio performance across time, allowing investment trends to be explored and changes in asset value to be identified.
Monitoring these trends provides a basis for understanding how investment activity and asset performance influence overall portfolio growth.

### Interactive Dashboard
The dashboard includes interactive filters that allow users to explore portfolio performance based on:
* *Investor Name*
* *Month*
* *Asset Type*
* *Risk Profile*
These filters allow the analysis to be narrowed to specific investment groups and provide a more detailed view of portfolio performance.

## Key Insights
The analysis revealed several insights into portfolio performance:
* Some assets demonstrated **strong growth trends**, contributing significantly to overall portfolio value.
* Investment allocation patterns influenced portfolio performance and diversification.
* Tracking asset progression helped identify **high-performing investments and underperforming assets**.
* Comparing current asset value with investment activity provided greater visibility into overall portfolio performance.
* Monitoring returns across different asset types supported a more structured approach to investment performance evaluation.
These insights illustrate how portfolio analytics can support **investment monitoring, performance evaluation, and data-driven decision-making**.

## Conclusion
An investment portfolio tracking dashboard was produced to provide a clear view of **asset performance and portfolio growth**.
The dashboard enables investment trends to be explored and asset performance to be monitored in an accessible visual format. By bringing together investment allocation, current asset value, returns, asset progression, and performance comparisons, the dashboard provides a centralized view of portfolio activity.
This project demonstrates how Power BI can be used to transform investment data into an interactive analytical tool that supports portfolio monitoring and performance evaluation.
